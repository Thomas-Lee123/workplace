# 服务器部署指南

> 适用：阿里云 ECS + Ubuntu 22.04 + 域名 lsy567.com

---

## 第一步：重装系统为 Ubuntu

1. 登录阿里云控制台 → 云服务器 ECS → 实例列表
2. 找到你的服务器 → 点右边"更多" → **"更换操作系统"**
3. 选择：
   - 镜像类型：公共镜像
   - 操作系统：**Ubuntu 22.04 64位**
4. 设置 root 密码（**记下来，后面一直要用**）
5. 确认更换，等 2-3 分钟完成

> 重装会清空服务器所有数据，如果上面有东西先备份。

---

## 第二步：SSH 连接服务器

### Windows 电脑

打开 PowerShell（Win 键 → 输入 powershell → 回车），输入：

```bash
ssh root@你的服务器公网IP
```

比如你的服务器 IP 是 `47.96.xxx.xxx`：

```bash
ssh root@47.96.xxx.xxx
```

首次会提示 `Are you sure you want to continue connecting?`，输入 `yes` 回车。

然后输入你第一步设置的 root 密码（输入时不显示，正常现象）。

### Mac 电脑

打开终端（Terminal），同样的命令。

> 服务器公网 IP 在阿里云控制台 → ECS → 实例列表里能看到。

---

## 第三步：基础环境配置

连上服务器后，逐条执行以下命令：

### 3.1 更新系统

```bash
apt update && apt upgrade -y
```

### 3.2 安装必要工具

```bash
apt install -y curl wget git nginx certbot python3-certbot-nginx ufw
```

### 3.3 配置防火墙

```bash
ufw allow 22        # SSH
ufw allow 80        # HTTP
ufw allow 443       # HTTPS
ufw enable
```

确认 `y` 回车。

### 3.4 安装 Node.js（使用 NodeSource 官方源）

```bash
curl -fsSL https://deb.nodesource.com/setup_22.x | bash -
apt install -y nodejs
```

验证安装：

```bash
node -v    # 应该显示 v22.x.x
npm -v     # 应该显示 10.x.x
```

### 3.5 安装 PostgreSQL

```bash
apt install -y postgresql postgresql-contrib
```

启动并设置开机启动：

```bash
systemctl start postgresql
systemctl enable postgresql
```

创建数据库和用户（把 `your_password` 换成你自己设的密码，**记下来**）：

```bash
sudo -u postgres psql
```

进入 psql 后执行（一行一行来）：

```sql
CREATE USER travel_user WITH PASSWORD 'your_password';
CREATE DATABASE travel_db OWNER travel_user;
GRANT ALL PRIVILEGES ON DATABASE travel_db TO travel_user;
\q
```

## 第四步：配置域名和 HTTPS

### 4.1 域名解析到服务器

1. 登录阿里云控制台 → 域名
2. 找到 `lsy567.com` → 解析设置
3. 添加两条记录：

| 记录类型 | 主机记录 | 记录值 |
|---------|---------|--------|
| A | @ | 你的服务器公网IP |
| A | www | 你的服务器公网IP |

等 2-5 分钟生效。

### 4.2 配置 Nginx

创建配置文件：

```bash
nano /etc/nginx/sites-available/travel
```

粘贴以下内容（先不改，后面部署了前端再回来改）：

```nginx
server {
    listen 80;
    server_name lsy567.com www.lsy567.com;

    # 前端静态文件（部署时会放到这里）
    root /var/www/travel;
    index index.html;

    # 前端页面
    location / {
        try_files $uri $uri/ /index.html;
    }

    # 后端 API 转发
    location /api/ {
        proxy_pass http://127.0.0.1:3000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_cache_bypass $http_upgrade;
    }
}
```

`Ctrl+O` 保存，`Ctrl+X` 退出。

启用配置：

```bash
ln -s /etc/nginx/sites-available/travel /etc/nginx/sites-enabled/
rm /etc/nginx/sites-enabled/default    # 删除默认配置
nginx -t                                # 测试配置是否正确
```

如果显示 `syntax is ok` 和 `test is successful`，继续：

```bash
systemctl reload nginx
```

### 4.3 申请免费 HTTPS 证书

```bash
certbot --nginx -d lsy567.com -d www.lsy567.com
```

按提示输入邮箱地址（用于证书到期提醒），一路同意。

完成后访问 `https://www.lsy567.com` 应该能看到 Nginx 默认页面（此时还没有部署前端代码）。

> 证书 90 天有效期，certbot 会自动续期，不用管。

## 第五步：部署项目

### 5.1 创建项目目录

```bash
mkdir -p /var/www/travel
mkdir -p /opt/travel-server
```

### 5.2 部署前端（以后每次更新都这样做）

在你的**本地电脑**上构建前端：

```bash
# 本地
npm run build    # 或 flutter build web
```

构建产物一般在 `dist/` 或 `build/` 目录。

上传到服务器：

```bash
# 本地 PowerShell/终端
scp -r ./dist/* root@你的服务器IP:/var/www/travel/
```

### 5.3 部署后端

在你的**本地电脑**上打包后端代码上传：

```bash
# 本地
scp -r ./server/* root@你的服务器IP:/opt/travel-server/
```

然后在服务器上：

```bash
# SSH 到服务器
cd /opt/travel-server
npm install
```

### 5.4 配置环境变量

在服务器上创建 `.env` 文件：

```bash
nano /opt/travel-server/.env
```

内容：

```
DATABASE_URL=postgresql://travel_user:your_password@localhost:5432/travel_db
PORT=3000
NODE_ENV=production
```

把 `your_password` 换成你第三步设置的数据库密码。

### 5.5 使用 PM2 保活后端

```bash
npm install -g pm2
cd /opt/travel-server
pm2 start index.js --name travel-api
pm2 save
pm2 startup
```

执行 `pm2 startup` 后会输出一条命令，复制粘贴执行即可（让服务器重启时自动启动你的应用）。

常用命令：

```bash
pm2 status          # 查看运行状态
pm2 logs travel-api # 查看日志
pm2 restart travel-api  # 重启
```

## 第六步：验证

1. 浏览器访问 `https://www.lsy567.com` → 应该看到前端页面
2. 浏览器访问 `https://www.lsy567.com/api/health` → 如果后端有 health 接口，应该返回 200

## 日常维护速查

| 操作 | 命令 |
|------|------|
| 更新前端 | 本地构建 → `scp` 上传到 `/var/www/travel/` |
| 更新后端 | 上传代码 → `npm install` → `pm2 restart travel-api` |
| 查看后端日志 | `pm2 logs travel-api` |
| 重启 Nginx | `systemctl reload nginx` |
| 查看磁盘 | `df -h` |
| 重启服务器后 | 不需要手动操作，PM2 和 Nginx 都会自动启动 |
