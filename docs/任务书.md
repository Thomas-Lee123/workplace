## 一、项目概况

"一键旅行"是一个旅行行程规划工具，核心思路是将旅行规划变成"购物车"体验——从不同平台选品（酒店/景点/餐饮），统一归入每日行程，支持 AI 生成、文件导入、价格预算追踪。

**技术栈：** React 19 + Vite 8（前端） / Express + Prisma + PostgreSQL（后端） / DeepSeek API（AI）

**部署：** 阿里云 ECS + Nginx + PM2 · 域名 lsy567.com

## 五、架构优化建议

### 5.1 当前架构问题
- `TripDetail.tsx` 过于臃肿（367 行，单一组件包含拖拽、聊天、编辑、导出等）
- AI 流式响应无断线重连
- 前端无状态管理库（纯 useState，跨组件通信靠 URL/CustomEvent/localStorage）

### 5.2 改进方向
- 拆分 TripDetail 为子组件（TripHeader / DayList / ItemBlock / ChatPanel）
- 引入 Zustand 轻量状态管理（或保持当前方案，但统一状态策略）
- AI SSE 连接增加重试逻辑和超时处理
